# G′ 研究能力清单（消融实验的非循环判据）

- 文档版本：v0.1（草案，待研究者审查）
- 状态：**候选判据，待验证**——本清单自身接受审计与修订（`design_risks.md` §0 自我审计条款）
- 关联：`docs/ablation_minimal_structure.md`（消融方法与第一轮推断）、`docs/design_risks.md`
  （H-ABL-001、R-019、Q-014）
- 用途：为"最小必要结构"消融提供**独立于模块划分**的能力判据

---

## 0. 为什么需要本清单（循环性问题）

原 G1–G7 与候选七模块**一一对应**（G5=V 的功能、G6=T 的功能、G7=Π 的功能……）。
以"删除模块 → 失去对应 G → 模块必要"为推理是**定义上为真**，不构成发现。

有效消融要求能力判据从**研究现象**导出，与实现与架构选择无关：

- 来源 A：任务书 Gate 3 研究过程动态管理清单（假设分裂 / 证据冲突 / 反例 /
  定义修改 / 路线淘汰 / 重新开放）；
- 来源 B：UCS 导入用例（`experiments/UCS/`）；
- 来源 C：2026 年外部案例分析（OpenAI Navier–Stokes 事件、BootLoops provenance 协议）；
- 来源 D：任务书可审计性要求（横切支撑）。

任何架构的系统都必须逐一满足本清单；删除某组件后哪条判据失效，
才是该组件必要性的证据。

**推断规则**：

1. 满足判据 ≠ 机制成立（R-019：测试通过的语义膨胀）；
2. 本清单第一版必然不完备（Q-014：未登记风险）——真实研究项目导入后须回填；
3. 清单版本须在消融实验开始前冻结，实验期间不得增删（防判据漂移）。

## 1. 动态能力（来源 A：Gate 3 研究过程动态管理）

| ID | 能力 | 可观察判据（有/无的判别） |
|----|------|--------------------------|
| G′01 | **假设分裂**：一个假设可裂为多个子假设，原假设的状态、历史与依赖保留 | 分裂后旧假设仍可按历史状态回放；子假设各自持未断言状态；无覆盖写 |
| G′02 | **证据冲突**：矛盾证据可共存登记，不静默覆盖，相关结论进入待审 | 冲突对双方证据均保留；结论状态出现待审/降级而非直接翻转 |
| G′03 | **反例处理**：反例可登记并触发现有结论降级/淘汰，来源可追溯 | 结论降级事件引用反例 ID；反例本身有产生记录 |
| G′04 | **定义修改**：定义产生新版本，引用方可被定位与复核 | 旧版本可回放；引用旧版本的义务/证明被影响报告列出（关联 R-017） |
| G′05 | **路线淘汰**：路线失效后，依赖它的结论不得保持"已确立" | 路线失效后下游命题状态出现失效/待审传播 |
| G′06 | **重新开放**：已关闭结论可重开，理由/依据/时间可追溯，历史不删 | 重开产生新事件并引用原关闭事件；原关闭记录仍可回放 |

## 2. 表达能力（来源 B：UCS 导入用例）

| ID | 能力 | 可观察判据 |
|----|------|-----------|
| G′07 | **未确认状态保持**：未确认信息以 unknown/none/pending 表达，不被填充为断言 | 导入后无任何节点被"填补"为已断言/已知状态 |
| G′08 | **关系假设登记**：对象间关系可作为未断言假设独立登记 | 关系以假设节点存在，relation/direction 可为空，`asserted=false` |
| G′09 | **封闭组合空间声明**：有限组合空间可声明为封闭，且不被当作已枚举/已判定 | 空间大小可声明；无具体组合被赋值 |
| G′10 | **必要性主张与反证条件结构化**：可表达"X 是必要的"及其可证伪条件（内容可待确认） | 字段存在且 `asserted=false` 直至人工确认（UCS `necessity_claim` 形态） |

## 3. 外部案例驱动能力（来源 C：2026 外部事件分析）

| ID | 能力 | 可观察判据 |
|----|------|-----------|
| G′11 | **先例审计**：新主张可被要求附先例/文献审计记录（防"复现已知结果"） | novelty 主张存在审计记录字段/事件；缺失时状态升级受阻（关联 R-023） |

## 4. 支撑性（横切）能力（来源 D：任务书可审计性要求）

| ID | 能力 | 可观察判据 |
|----|------|-----------|
| G′13 | **可回溯**：任意当前状态可回答"何时、依据什么、由谁决定" | 事件级哈希链可回放；决策事件有 actor/reasoning |

## 5. 与原 G1–G7 的关系

G1–G7 **保留**用于实现层自检，但任何"必要性"主张必须对 G′ 论证：

| 原能力 | 服务的 G′ | 备注 |
|--------|----------|------|
| G1 表达研究对象 | G′01–G′06 的对象锚定 | 锚定是能力，可散在身份机制中，不必然需要独立模块 |
| G2 组织研究结构 | G′04、G′05、G′14 | |
| G3 产生证明义务 | G′10 + 判定标准 | |
| G4 获得并保存证据 | G′02、G′03 的物质基础 | |
| G5 判断证据是否支持结论 | G′02、G′03、G′05、G′12 | V 的功能 |
| G6 根据结果更新知识 | G′01–G′06 | T 的功能 |
| G7 自主选择下一步 | **不在 G′ 中** | 见下节 |

**G7 的特殊处理**：自主性不是研究现象，而是系统运行模式属性，无法从 Gate 3 / UCS /
外部案例导出。其必要性单独按**自主性判据**评估（仅方向 D / Π 需要）：

- A′01（候选，待定义）：在无外部人类输入时，系统能否基于当前状态产生候选下一步
  并完成选择？——判据未给出操作化步骤，**待定义**。

这与"Π 对自主 RDE 必要、对人类驱动的研究状态管理未必必要"的初步判断一致。

## 6. 清单的已知局限（不隐藏）

1. 第一版从二手材料（任务书、UCS 文本、外部报道）导出，**未经真实研究活动验证**；
2. 无优先级、无权重（不排序，避免预设）；
3. 判据是行为级描述，尚未给出操作化测试步骤（步骤属消融文档的测试协议）；
4. 不含性能/规模类能力（R-014 / Q-011 另行处理）；
5. 不含"研究结论正确性"类判据——正确性不由结构能力保证（理论边界 3/4/5）。
