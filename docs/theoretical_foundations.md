# 理论边界（Theoretical Foundations & Boundaries）

文档版本：v0.1 ｜ 状态：**约束性文档**（与 README 同步维护）

## 1. 九条理论边界（任务书第 8 节原文）

1. RDE 目前是研究假说和架构探索，不是已经证明的 AGI 理论。
2. 研究知识图谱不等于智能本身。
3. 逻辑一致性不等于现实正确性。
4. 形式化证明不等于经验真实性。
5. 证据支持不等于数学证明。
6. 研究过程可复现不等于研究结论正确。
7. 多 Agent 协作不自动产生集体智能。
8. 研究策略的自我评价不能替代外部验证。
9. 显式图结构未必是唯一实现方式，隐式动力学也可能实现相同功能。

## 2. 每条边界的操作含义

| # | 边界 | 对 RDE 工程的具体约束 |
|---|------|----------------------|
| 1 | 非已证明 AGI 理论 | 所有文档用"假说/待验证"；禁止"证明了""表明 AGI 需要…"表述 |
| 2 | 图谱 ≠ 智能 | 图谱只是状态载体；不从"图谱完备"推断"系统智能" |
| 3 | 一致性 ≠ 现实正确 | 事件日志内无矛盾不构成任何经验结论；系统须报告"逻辑一致但未验证" |
| 4 | 证明 ≠ 经验真实 | `entails` 路径与 `supports` 路径在数据模型与验收路径上分离 |
| 5 | 证据 ≠ 证明 | 证据状态 `supported` 永不自动转成语义 `true_in_scope`（状态机强制） |
| 6 | 可复现 ≠ 正确 | 回放一致性测试只验证确定性，不验证结论真值；验收项 1 与 9 分开测试 |
| 7 | 多 Agent ≠ 集体智能 | 第一阶段禁止大规模多 Agent；未来实验须独立外部评估 |
| 8 | 自我评价 ≠ 外部验证 | 决策有效性评估必须能绑定外部结果；审计（`research_log/audits/`）需外部/人类签署 |
| 9 | 显式图 ≠ 唯一实现 | 架构文档记录替代实现路径（隐式动力学），见 architecture.md §7（待决 Q-ARCH-001） |

## 3. 逻辑与经验的双轨验收

对应验收标准第 9 条"数学证明和经验支持有不同的验收路径"：

- **数学/逻辑轨**：`Derivation` 完成 → 只允许转换命题语义状态（在绑定假设与范围内）；验收依据是推导链条的完整重放与依赖检查。
- **经验轨**：`Evidence`/`Experiment` 追加 → 只允许转换证据状态；验收依据是证据来源、可复现记录、冲突处理。
- 两轨**互不授予对方的状态**：见 state_semantics.md 中的非法转换表（如 `mixed → true_in_scope` 由证据触发即非法）。

## 4. 本边界文档自身的可证伪性

- 若发现任何交付物出现违反九条边界的表述 → 视为文档缺陷（bug），记录到 `research_log/counterexamples/`。
