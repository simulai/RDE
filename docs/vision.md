# 愿景（Vision）

文档版本：v0.1 ｜ 状态：**架构假说，待验证**

## 1. 定位

RDE 不是自动科研工具，也不是多 Agent 任务调度器。

长期研究目标（假说 H-VIS-001）：

> 构建能够管理自身知识状态、持续形成和修订信念、根据证据调整研究方向，并保持长期认知连续性的机制。

任务书明确要求：这只是一条**待验证的架构与理论假说，不得写成已证明的 AGI 必要条件**。

## 2. 核心研究问题

> 一个有限智能系统，如何从持续产生的新信息中，形成稳定但可修订的信念和知识，并保持跨时间的认知连续性？

该问题拆解为四项可操作子问题 R1–R4，见 [research_questions.md](research_questions.md)。

## 3. 基本循环

```
候选生成 → 约束 → 推导 → 验证 → 结晶 → 后果反馈 → 知识修订 → 新的研究策略
```

RDE 第一阶段只实现循环中与**知识状态管理**有关的最小闭包：

- 候选生成、推导、验证：以节点/边/事件的形式**记录**（不自动执行推理）；
- 结晶：推导通过 → 命题状态转换（受状态机约束）；
- 后果反馈：证据追加 → 证据状态转换；
- 知识修订：基础节点变化 → 依赖影响报告（M5）；
- 新的研究策略：决策记录（M7）。

> 待决 Q-VIS-001：循环中"策略如何生成"不在第一阶段范围；第一阶段只保证**每一步策略都可被记录与回溯**，不保证策略质量。

## 4. 与 AGI 研究的关系（克制表述）

RDE 可能成为 AGI 的重要组成部分——这是一个**研究动机**，不是结论。第一阶段交付的任何内容都不构成对以下命题的支持：

- "显式知识图谱是 AGI 必要组件"（见理论边界第 9 条）；
- "逻辑一致性 ⟹ 现实正确"（第 3 条）；
- "研究系统自我评价足以替代外部验证"（第 8 条）。
