# 研究问题（Research Questions）

文档版本：v0.1 ｜ 状态：四项均为**开放研究问题**，非已解决项

暂定四项基础研究问题。每项给出：问题、必须区分的维度、不可做的简化、第一阶段的最小可交付、以及**可证伪条件**（什么情况下该问题上的当前方案算失败）。

---

## R1：知识状态管理

**问题**：如何区分以下六类命题状态——

1. 已经形式化的命题
2. 已经证明的命题
3. 有实验支持的命题
4. 存在反例的命题
5. 证据互相冲突的命题
6. 尚未获得足够信息的命题

**不可做的简化**：不能用 True / False / Unknown 三值覆盖全部状态。

**必须分离的三个状态维度**（见 [state_semantics.md](state_semantics.md)）：

| 维度 | 回答的问题 |
|------|-----------|
| 命题语义状态 | 在给定假设与适用范围内，命题本身成立/不成立/欠定？ |
| 认识与证据状态 | 我们当前掌握的证据支持/反驳/混杂/不足/已失效？ |
| 项目执行状态 | 该对象在研究流程中处于 proposed/active/blocked/…？ |

典型反例（说明三值不够）：一个命题可以**语义上 unknown** 同时**证据上 supported**（在更窄范围内被支持）；也可以**语义上 true_in_scope** 同时**证据上 mixed**（证明成立但经验后果与预测冲突）。三值模型无法表达这两种情形。

**第一阶段交付**：三套枚举 + 合法/非法转换表 + 状态机代码（`core/state_machine`）+ 测试（含非法升级）。

**可证伪条件 F-R1**：
- F-R1.1：存在一对真实研究情形，其状态需违反本方案的任一合法转换才能正确表达 → 需修订转换表。
- F-R1.2：系统出现"实验结果较好 → 命题自动升级为数学定理"的路径 → 违反原则 2/3，方案失败。

## R2：逻辑依赖与影响传播

**问题**：当一个基础定义、假设或定理被修改或推翻时：

- 哪些下游命题受到影响？
- 哪些证明需要重新检查？
- 哪些实验结论需要重新解释？
- 哪些研究路线应当停止？
- 哪些结果仍然有效？

**关键约束**：必须支持**多条独立证明路线**——一条路线失效不代表结论失效（任务书 Task 5、验收标准 5）。

**第一阶段交付**：影响传播算法（[dependency_propagation.md](dependency_propagation.md)），输出结构化影响报告（受影响集 / 仍有效集 / 需人工复核集），代码 `core/dependency_analysis` + 测试。

**可证伪条件 F-R2**：
- F-R2.1：构造两条共享同一被推翻前提的"看似独立"路线，若系统仍报告结论有效 → 独立性判定错误（何为独立是开放问题 Q-DEP-001）。
- F-R2.2：修改基础节点后存在下游节点未被报告 → 传播不完整，方案失败。

## R3：有限预算下的研究策略选择

**问题**：系统如何判断下一步最值得研究什么？候选考量：

信息增益、关键依赖程度、反证价值、可执行性、计算成本、跨项目复用价值、对长期研究目标的贡献。

**不可做的简化**：**不要**直接把这些指标合并成不可解释的单一评分（任务书第 12 节禁止"压缩成一个评分"）。

**第一阶段交付**：决策记录结构（M7：目标、可选动作、选择理由、预算、预期信息价值、实际结果、决策是否有效）+ `Decision` 节点 schema。**不实现**打分或推荐算法。

**可证伪条件 F-R3**：
- F-R3.1：任何实现引入一个对上述指标加权求和的标量用于排序 → 违反设计约束，需要改为可解释的分层/帕累托/词典序比较并记录比较理由。
- F-R3.2：决策记录缺少"预期 vs 实际"字段 → 无法事后审计决策有效性，方案失败。

**待决 Q-R3-001**：不合并评分时如何做可比较的策略选择（词典序？Pareto 前沿？约束满足 + 词典序？）——第一阶段不裁决。

## R4：研究策略自身的修订

**问题**：系统能否发现——

- 当前问题定义有误
- 研究假设不成立
- 实验判据存在漏洞
- 当前路线没有信息价值
- 评价标准出现偏差
- 研究目标需要重新审查

**原则**：研究系统必须允许质疑自身的研究策略。

**张力（风险 R-015）**：自我质疑机制本身可能被系统自我评价同化，从而失去效力（理论边界第 8 条：自我评价不能替代外部验证）。

**第一阶段交付**：使"质疑策略"成为一等对象——`Question` 节点可针对 `Decision`/`Question` 本身（边 `motivates`、`blocks`），策略修改写入事件日志并可回溯；`research_log/hypotheses/` 与 `research_log/audits/` 目录约定。

**可证伪条件 F-R4**：
- F-R4.1：系统中不存在指向自身决策节点的质疑路径（即无法表示"这个决策可能有问题"）→ 方案失败。
- F-R4.2：策略修订仅由系统自我评分触发、无外部证据或人类授权 → 违反原则 9/10。
