# research_log/

人类可读的研究日志目录（与 core/ 中的机器事件日志互补；事件日志是真相源，这里是叙述层）。

| 子目录 | 用途 | 规则 |
|--------|------|------|
| `decisions/` | 研究决策叙述（对应 M7 `Decision` 节点与 `decision_recorded` 事件） | 每条含目标、选项、理由、预算、预期价值、实际结果、有效性 |
| `hypotheses/` | 假说登记（H-xxx 的叙述版本） | 未证明前不得改写为陈述句无标记版本 |
| `counterexamples/` | 反例记录（原则 5：反例必须能改变知识状态，且本身不可删除） | 含命中的推导路线与触发的状态转换事件 ID |
| `audits/` | 审查记录（理论边界 §3、原则 10） | 须注明审查者身份；agent 审计不授予状态升级 |

状态标记规范见 `docs/epistemic_status.md`；风险与开放问题的权威登记在 `docs/design_risks.md`。
**RDE 本身也必须接受 RDE 的审计。**
